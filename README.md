# SFTP 批次檔案檢索與結構保留下載工具 (SFTP Batch Downloader)

一套專為工程與資料分析人員打造的現代化 SFTP 批次下載工具。具備動態純目錄階層自適應、遠端資料夾圖形瀏覽器、模糊與精準比對、最後目錄萬用字元檔案檢索、以及本地鏡像目錄結構完整保留等強大特性。

相容 Windows 11 Smart App Control (SAC) 與企業高強度防毒環境，支援單一 EXE 與綠色便攜免安裝包發布。

---

## ✨ 核心特色

1. **Excel 動態純目錄階層自動適配**
   - 從 Excel 複製幾欄，表格就自動動態展開為幾層目錄（如 `第 1 層目錄`、`第 2 層目錄` ... `第 N 層目錄`）。
   - 支援 `Ctrl+V` 一鍵貼上、雙擊儲存格直接編輯，操作直覺流暢。

2. **最後目錄之目標檔案萬用字元檢索**
   - 遍歷引擎根據設定的階層結構精準定位至各列的「最後一層目錄」。
   - 在該目錄下依「目標檔案過濾」條件（例如 `*RAW*`、`*RAW*-*.csv`）批次找出目標檔案進行下載；留空則全選下載。

3. **雙重目錄比對模式切換**
   - **模糊包含 (Contains - 預設)**：目錄名稱只要包含關鍵字即符合。
   - **完全精準相符 (Exact Match)**：目錄名稱必須與關鍵字完全相同（大小寫不敏感）。
   - **萬用字元優先**：當關鍵字包含 `*` 或 `?` 時，自動啟用標準 Glob 模式比對。

4. **遠端路徑圖形瀏覽器 (`[瀏覽遠端...]`)**
   - 告別手動背誦與輸入複雜的 Linux 路徑。
   - 點擊按鈕即可連線即時瀏覽遠端伺服器目錄樹，支援雙擊進入資料夾、回上一層、重新整理，並能一鍵帶回主介面。

5. **本地鏡像目錄結構保留與安全下載**
   - 下載時自動於本機建立相同階層的目錄樹：`本地根目錄 / 第 1 層 / 第 2 層 / ... / 檔案名稱`。
   - 採用 `.part` 暫存檔原子寫入機制，確保下載未完成前不破壞舊檔。
   - 支援同步遠端最後修改時間 (mtime) 與檔案大小比對略過機制。

6. **自動產出完整 Manifest 下載清單 CSV**
   - 下載任務完成時，自動於本地下載目錄生成 `下載清單_YYYYMMDD_HHMMSS.csv`。
   - 涵蓋 10+ 大欄位（序號、各層目錄、檔名、本地路徑、遠端路徑、檔案大小、易讀容量、處理狀態、說明、時間）。
   - 採用 `utf-8-sig` 編碼，Excel 開啟不亂碼，介面提供 `[📑 開啟下載清單 (Excel)]` 一鍵檢視。

7. **100% 免疫 Windows 11 Smart App Control (SAC)**
   - 採用 CustomTkinter 現代化暗色介面與原生 Python 執行期環境，免除無簽名可執行檔被系統攔截的困擾。

## 🖥️ 介面預覽與操作指南

### 1. SFTP 連線設定
- **第一列**：`主機 (Host)`、`Port` (預設 22)、`帳號 (Username)`、`密碼 (Password)`（附眼睛按鈕可切換遮罩顯示）。
- **第二列**：`遠端初始路徑`、`[瀏覽遠端...]`（圖形化目錄瀏覽器）、`記住連線資訊`、`[測試連線]`。

### 2. 目錄階層與比對規則
- **貼上 Excel 資料**：在 Excel 選取目錄欄位後複製，回到工具點選 `[📋 貼上 Excel 清單 (Ctrl+V)]` 或直接按下 `Ctrl+V`。
- **比對模式**：可依需求切換 `模糊包含 (Contains)` 或 `完全精準相符 (Exact)`。
- **清空表格**：點選 `[🗑️ 清空表格]` 即可重置規則。

### 3. 下載與全域設定
- **目標檔案過濾**：例如輸入 `*RAW*` 或 `*RAW*-*.csv`，多個條件可用分號 `;` 分隔。留空代表下載最後目錄下的所有檔案。
- **重複檔案處理**：
  - `比對大小與修改時間略過 (推薦)`
  - `直接覆蓋`
  - `已存在則略過`
- **本地儲存路徑**：指定下載到本地電腦的資料夾路徑。

### 4. 執行與報表
- 點選 `[▶ 開始搜尋與下載]` 開始非同步背景傳輸，即時顯示進度條、當前檔案與統計數字。
- 點選 `[⏹ 停止]` 可安全中斷作業。
- 點選 `[📑 開啟下載清單 (Excel)]` 可直接呼叫系統關聯之 Excel 開啟下載報表 CSV。
- 點選 `[📁 開啟下載資料夾]` 快速開啟本地下載根目錄。

## 🚀 快速開始 (原始碼執行)

### 環境需求
- Python 3.10 或以上版本
- Windows 10 / 11

### 1. 安裝相依套件
```bash
pip install -r requirements.txt
```

### 2. 啟動應用程式
直接雙擊 `start.bat`，或在命令列執行：
```bash
python main.py
```

## 📦 打包發布 (Distribution)

本專案提供兩種發布建置方式，均支援純 ASCII 批次腳本一鍵自動化建置：

### 方式 A：編譯為獨立單一 EXE 檔 (`dist/SFTP批次下載工具.exe`)
適合一般使用者，無需安裝 Python 環境：
```bat
build_exe.bat
```
腳本將透過 `SFTPTool.spec` 收集 CustomTkinter 與 Paramiko 依賴，輸出無主控台黑視窗的單檔可執行程式。

### 方式 B：建置綠色免安裝便攜包 (`dist/SFTP批次下載工具_綠色便攜版.zip`)
**⭐ 企業嚴格網域與 Windows 11 Smart App Control (SAC) 環境強烈推薦！**
```bat
build_portable.bat
```
自動建立隔離的 Python 原生執行環境，隨附官方微軟簽署之 DLL，內建 `啟動工具.bat`，解壓縮即可雙擊運行，絕不被防毒軟體或 SAC 誤殺。

## 📁 專案架構

```text
FTPtool/
├── core/                       # 核心商務邏輯與後端引擎
│   ├── config_manager.py       # 設定檔持久化與 XOR 密碼混淆
│   ├── download_manager.py     # 原子下載、衝突處理與 Manifest CSV 產出
│   ├── sftp_manager.py         # Paramiko SFTP 連線與遠端目錄走訪
│   ├── traverse_engine.py      # 動態多階層遞迴走訪與實體快取引擎
│   └── worker.py               # 背景執行緒與 UI 訊號節流分派
├── models/                     # 資料模型定義
│   └── data_models.py          # SFTPConfig, RuleItem, ReportRecord 等資料結構
├── ui/                         # 圖形使用者介面 (CustomTkinter)
│   ├── main_window.py          # 主視窗佈局、狀態管理與事件迴圈
│   ├── remote_browser_dialog.py# 遠端路徑圖形化瀏覽器對話框
│   └── rule_table_ctk.py       # 動態純目錄自適應表格 (支援 Excel 貼上與編輯)
├── tests/                      # 完整自動化測試套件
│   ├── test_phase1.py ~ test_phase8_pure_dirs.py
│   └── test_all.py             # 一鍵回歸測試執行腳本
├── build_exe.bat               # PyInstaller 單檔 EXE 打包腳本
├── build_portable.bat          # 綠色便攜包建置批次檔
├── build_portable.py           # 便攜包生成與 ZIP 壓縮邏輯
├── requirements.txt            # Python 相依清單
├── SFTPTool.spec               # PyInstaller 打包規格檔
├── start.bat                   # 原始碼一鍵啟動腳本
└── main.py                     # 應用程式進入點
```
