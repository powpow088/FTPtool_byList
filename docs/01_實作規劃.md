## 二、 四大技術深水區：核心演算法與架構設計

### 深水區 1：【遍歷效能與樹狀分組 (Rule Tree & Directory Caching)】

#### 問題痛點

使用者從 Excel 貼上 200 列規則時，常出現大量重複的第 1 層或第 2 層條件（例如 50 列都是 `L1="PART_A"`，搭配不同的 `L2` 與 `File`）。若採逐列（Row-by-Row）傻瓜式遍歷，會對遠端伺服器發出數百次重複的 `sftp.listdir_attr()`，在跨國或高延遲網路下（每次 RTT 100~300ms）將導致嚴重的效能瓶頸。此外，因為支援模糊比對，一個實體目錄（如 `PART_A_01`）可能同時滿足兩個不同的關鍵字規則（如 `PART_A` 與 `01`），若未做實體路徑去重，會引發重複下載。

#### 解決方案：雙階段「規則樹編譯 + 實體目錄展開快取」

我們設計**兩階段漏斗演算法**：

1. **階段一：規則預編譯樹 (`RuleTree`)**
將扁平的表格列依字串正規化（小寫、去空白）後，聚合為 `Dict[L1_Pattern, Dict[L2_Pattern, Set[File_Pattern]]]`。


2. **階段二：實體路徑快取與反向映射 (`Physical Path Resolution`)**
* `Initial Path` 只執行 **1 次** `listdir_attr()`。


* 比對所有 `L1_Pattern`，將命中的「實體 L1 目錄名稱」作為新的 Key，將其對應的 `L2_Pattern -> Set[File_Pattern]` 進行聯集（Union）合併。
* 每個命中的「實體 L1 目錄」只執行 **1 次** `listdir_attr()`。
* 比對該實體 L1 下的所有 `L2_Pattern`，將命中的「實體 `(L1_Dir, L2_Dir)`」作為 Key，合併其下所有的 `File_Pattern` 集合。
* 每個命中的「實體 L2 目錄」只執行 **1 次** `listdir_attr()`，並一次比對該目錄收集到的所有 `File_Pattern`。



**效能保證**：無論表格有 10 列還是 10,000 列，**遠端任何一個實體資料夾最多只會被呼叫 1 次 `listdir_attr()**`，且完美保留規格書要求的「成對路徑關聯性（不產生笛卡兒積交叉污染）」。

### 深水區 2：【Excel Ctrl+V 深度互動與邊界處理】

#### 問題痛點

Excel 複製到剪貼簿的格式為 TSV（Tab-Separated Values），但實務上包含多種髒資料與邊界狀況：

1. Windows 換行為 `\r\n`，Mac/Linux 為 `\n`，且 Excel 複製區塊的**最後一尾端常自帶一個空換行**。
2. 儲存格內若包含換行或特殊字元，Excel 會自動在字串外包覆雙引號 `"..."`，且內部雙引號會變成 `""`。
3. 使用者可能停留在表格的第 $N$ 列、第 $M$ 欄按下 `Ctrl+V`，或是反白多列後貼上。

#### 解決方案：基於 `csv.reader(dialect='excel-tab')` 的狀態感知貼上引擎

不使用脆弱的 `text.split('\n')` 與 `line.split('\t')`，改用 Python 內建的 `csv.reader(io.StringIO(raw_text), dialect='excel-tab')`，直接原支援雙引號脫逸與跨平台換行。

#### 欄位自動適配與座標對齊演算法

1. **決定起始列 (`start_row`)**：
* 若使用者目前有選取儲存格，取 `selectedIndexes()` 中最小的 `row()`。
* 若無選取，且表格最後一列為全空白，則從該空白列開始填入；否則附加於表格最末端 (`rowCount()`)。


2. **清洗與過濾**：
* 每個 cell 執行 `cell.strip().strip('"').strip("'")`。


* 若整列解析後所有欄位皆為空字串，視為 Excel 尾端多餘空列，直接跳過。




3. **1 / 2 / 3 / 4+ 欄自動適配邏輯（無條件對齊表格絕對欄位 0, 1, 2）**：
* 為符合規格書定義，貼上時統一以列為單位寫入 Column 0 (L1)、Column 1 (L2)、Column 2 (File)：


* `len(row) == 1`：`[col[0], "", ""]`
* `len(row) == 2`：`[col[0], col[1], ""]`
* `len(row) == 3`：`[col[0], col[1], col[2]]`
* `len(row) >= 4`：`[col[0], col[1], col[2]]`，並將 `truncated_flag = True`（貼上完成後統一彈出一次 `QMessageBox.information` 提示已忽略第 4 欄以後的資料，避免迴圈內連彈視窗）。






4. **動態擴增與 UI 效能鎖定**：
* 貼上前呼叫 `setUpdatesEnabled(False)` 與 `blockSignals(True)`，計算所需總列數 `required_rows = start_row + len(parsed_rows)`，若大於目前 `rowCount()` 則一次呼叫 `setRowCount(required_rows)`，填完後再解鎖重繪，即使一次貼上 5,000 列也能在 10ms 內瞬間完成。

### 深水區 3：【執行緒訊號節流 (Signal Throttling) 與批次日誌渲染】

#### 問題痛點

1. **傳輸進度洪峰**：Paramiko 的 `sftp.get(remotepath, localpath, callback)` 每收到一個網路封包（通常每 32KB）就會觸發一次 `callback(transferred, total)`。在 1Gbps 內網下載 500MB 檔案時，1 秒內會觸發超過 **15,000 次** callback。若每次都直接 `emit` Qt Signal，主執行緒的 Event Queue 會瞬間塞爆，導致 GUI 完全凍結（Not Responding）。


2. **日誌洗版卡頓**：掃描上千個資料夾與略過檔案時，高頻率呼叫 `QTextEdit.append()` 會觸發頻繁的 DOM 重排與捲軸重繪，且日誌無限增長會耗盡記憶體。



#### 解決方案：雙層節流閥 (Time & Delta Gatekeeper + UI RingBuffer Timer)

1. **Worker 端：進度訊號時間與幅度雙重閘門 (`ProgressThrottler`)**
* 在 `DownloadWorker` 內記錄 `last_emit_time: float` 與 `last_emit_percent: int`。
* 當 Paramiko callback 觸發時，透過 `time.monotonic()` 檢查：
**僅當 `(now - last_emit_time >= 0.08)` (約 12 FPS，80ms) 且 `(current_pct != last_emit_percent)`，或者 `transferred == total` (100% 完成瞬間) 時**，才真正發射 `sig_file_progress.emit()`。這將每秒 15,000 次訊號直接降載至每秒最多 12 次。


2. **UI 端：日誌佇列與 100ms 批次渲染 (`LogBatchRenderer`)**
* Worker 發射 `sig_log(level, msg)` 後，MainWindow 的 Slot **不直接寫入 `QTextEdit**`，而是將格式化後的 HTML 字串推入 `collections.deque` 緩衝佇列。
* MainWindow 配置一個 `QTimer`（間隔 100ms），每次觸發時將 `deque` 內累積的數十條日誌以 `"".join(batch)` 一次性透過 `QTextCursor.insertHtml()` 寫入底部，並限制 `QTextEdit.document().setMaximumBlockCount(5000)` 自動淘汰最舊日誌，徹底根除 UI 卡頓。



---

### 深水區 4：【SFTP 狀態機、例外分流與優雅中止 (Graceful Cancellation)】

#### 問題痛點

Paramiko 的例外繼承體系較為底層（例如 `SFTPError`、`SSHException`、`socket.timeout`、`EOFError` 與內建的 `PermissionError` / `FileNotFoundError` 混用），且 `sftp.get()` 是一個阻塞式呼叫（Blocking Call）。如果使用者在下載一個 2GB 的大檔案時點擊「停止」，若等到整個檔案載完才檢查 `is_cancelled`，程式看起來就像死當。

#### 解決方案：Callback 內嵌例外中斷與四級例外分流矩陣

##### 1. 毫秒級中斷大型檔案下載 (Immediate Abort via Callback Exception)

* 定義專屬自訂例外 `class TaskCancelledError(Exception): pass`。
* 在傳遞給 `sftp.get(..., callback=self._transfer_callback)` 的回呼函式中，第一行即檢查 `if self._cancel_event.is_set(): raise TaskCancelledError("使用者主動中斷")`。


* 一旦拋出此例外，Paramiko 會立即中斷底層迴圈並跳出 `sftp.get()`。
* **清理髒檔案（Atomic Cleanup）**：為防止中斷或斷線在本地留下載一半的損毀檔案，所有下載統一先寫入暫存檔 `local_path + ".part"`。僅當 `sftp.get()` 完整走完且未拋出例外時，才執行 `os.replace(temp_path, local_path)` 並透過 `os.utime()` 同步遠端 `mtime`。若捕捉到 `TaskCancelledError` 或網路例外，立即在 `finally` 區塊刪除 `.part` 暫存檔。

### 2. `core/config_manager.py` — 設定檔持久化與密碼保護

```python
import base64
import json
import os
from pathlib import Path
from typing import Tuple, List
from models.data_models import SFTPConfig, SearchSettings, RuleItem, ConflictStrategy

class ConfigManager:
    """負責讀寫 config.json，並對儲存的密碼進行混淆保護"""
    
    DEFAULT_CONFIG_PATH = Path("config.json")
    _OBFUSCATION_SALT = b"SFTP_BATCH_DOWNLOADER_2026_KEY"

    @classmethod
    def load_config(cls, path: Path = DEFAULT_CONFIG_PATH) -> Tuple[SFTPConfig, SearchSettings, List[RuleItem]]:
        if not path.exists():
            return SFTPConfig(), SearchSettings(), []
        try:
            with open(path, "r", encoding="utf-8") as f:
                data = json.load(f)
            
            conn = data.get("connection", {})
            save_pwd = bool(conn.get("save_password", False))
            raw_pwd = cls._deobfuscate(conn.get("saved_password", "")) if save_pwd else ""
            
            sftp_cfg = SFTPConfig(
                host=conn.get("host", "").strip(),
                port=int(conn.get("port", 22)),
                username=conn.get("username", "").strip(),
                password=raw_pwd,
                save_password=save_pwd,
                initial_path=conn.get("initial_path", "/")
            )
            
            ss = data.get("search_settings", {})
            strategy_val = ss.get("conflict_strategy", ConflictStrategy.SIZE_MTIME.value)
            try:
                strategy = ConflictStrategy(strategy_val)
            except ValueError:
                strategy = ConflictStrategy.SIZE_MTIME

            search_cfg = SearchSettings(
                global_pattern=ss.get("global_pattern", ""),
                conflict_strategy=strategy,
                local_save_path=ss.get("local_save_path", "")
            )
            
            rules = [
                RuleItem(
                    l1_keyword=r.get("l1_keyword", ""),
                    l2_keyword=r.get("l2_keyword", ""),
                    file_pattern=r.get("file_pattern", "")
                )
                for r in data.get("rules", [])
            ]
            return sftp_cfg, search_cfg, rules
        except Exception:
            return SFTPConfig(), SearchSettings(), []

    @classmethod
    def save_config(
        cls,
        sftp_cfg: SFTPConfig,
        search_cfg: SearchSettings,
        rules: List[RuleItem],
        path: Path = DEFAULT_CONFIG_PATH
    ) -> None:
        encoded_pwd = cls._obfuscate(sftp_cfg.password) if sftp_cfg.save_password else ""
        payload = {
            "connection": {
                "host": sftp_cfg.host.strip(),
                "port": sftp_cfg.port,
                "username": sftp_cfg.username.strip(),
                "save_password": sftp_cfg.save_password,
                "saved_password": encoded_pwd,
                "initial_path": sftp_cfg.initial_path.strip()
            },
            "search_settings": {
                "global_pattern": search_cfg.global_pattern.strip(),
                "conflict_strategy": search_cfg.conflict_strategy.value,
                "local_save_path": search_cfg.local_save_path.strip()
            },
            "rules": [
                {
                    "l1_keyword": r.l1_keyword,
                    "l2_keyword": r.l2_keyword,
                    "file_pattern": r.file_pattern
                }
                for r in rules if not r.is_completely_empty()
            ]
        }
        with open(path, "w", encoding="utf-8") as f:
            json.dump(payload, f, ensure_ascii=False, indent=2)

    @classmethod
    def _obfuscate(cls, plain_text: str) -> str:
        if not plain_text:
            return ""
        data = plain_text.encode("utf-8")
        xored = bytes(b ^ cls._OBFUSCATION_SALT[i % len(cls._OBFUSCATION_SALT)] for i, b in enumerate(data))
        return base64.urlsafe_b64encode(xored).decode("ascii")

    @classmethod
    def _deobfuscate(cls, encoded_text: str) -> str:
        if not encoded_text:
            return ""
        try:
            xored = base64.urlsafe_b64decode(encoded_text.encode("ascii"))
            data = bytes(b ^ cls._OBFUSCATION_SALT[i % len(cls._OBFUSCATION_SALT)] for i, b in enumerate(xored))
            return data.decode("utf-8")
        except Exception:
            return ""

```

### 3. `core/sftp_manager.py` — SFTP 連線管理與心跳維護

```python
import socket
import stat
from typing import List, Tuple, Callable, Optional
import paramiko
from models.data_models import SFTPConfig

class SFTPManager:
    """封裝 Paramiko SSH/SFTP 連線、KeepAlive 心跳與安全重連機制"""

    SOCKET_TIMEOUT = 15.0
    KEEPALIVE_INTERVAL = 30

    def __init__(self, config: SFTPConfig) -> None:
        self._config = config
        self._ssh: Optional[paramiko.SSHClient] = None
        self._sftp: Optional[paramiko.SFTPClient] = None

    def connect(self) -> None:
        """建立 SSH 與 SFTP 連線，並設定 Timeout 與 KeepAlive"""
        self.close()
        self._ssh = paramiko.SSHClient()
        self._ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
        
        self._ssh.connect(
            hostname=self._config.host.strip(),
            port=self._config.port,
            username=self._config.username.strip(),
            password=self._config.password,
            timeout=self.SOCKET_TIMEOUT,
            banner_timeout=self.SOCKET_TIMEOUT,
            auth_timeout=self.SOCKET_TIMEOUT,
            look_for_keys=False,
            allow_agent=False
        )
        
        transport = self._ssh.get_transport()
        if transport:
            transport.set_keepalive(self.KEEPALIVE_INTERVAL)
            
        self._sftp = self._ssh.open_sftp()
        if self._sftp.get_channel():
            self._sftp.get_channel().settimeout(self.SOCKET_TIMEOUT)

    def test_connection(self) -> Tuple[bool, str]:
        """供 GUI『測試連線』按鈕呼叫，驗證認證與 Initial Path 是否存在且為目錄"""
        try:
            self.connect()
            init_path = self._config.initial_path.strip() or "/"
            attr = self._sftp.stat(init_path)
            if not stat.S_ISDIR(attr.st_mode):
                return False, f"遠端路徑存在但不是一個資料夾：{init_path}"
            return True, f"連線成功！已驗證遠端目錄：{init_path}"
        except paramiko.AuthenticationException:
            return False, "認證失敗：帳號或密碼錯誤。"
        except FileNotFoundError:
            return False, f"遠端初始路徑不存在：{self._config.initial_path}"
        except PermissionError:
            return False, f"權限不足：無法存取遠端初始路徑 {self._config.initial_path}"
        except (socket.timeout, TimeoutError):
            return False, f"連線逾時（超過 {int(self.SOCKET_TIMEOUT)} 秒），請檢查 Host 與 Port。"
        except Exception as e:
            return False, f"連線發生異常：{type(e).__name__} - {str(e)}"
        finally:
            self.close()

    def reconnect(self) -> None:
        """斷線重連"""
        self.close()
        self.connect()

    def listdir_attr(self, remote_path: str) -> List[paramiko.SFTPAttributes]:
        """取得遠端目錄內容屬性清單"""
        if not self._sftp:
            raise paramiko.SSHException("SFTP 尚未連線")
        return self._sftp.listdir_attr(remote_path)

    def download_file(
        self,
        remote_path: str,
        local_temp_path: str,
        callback: Optional[Callable[[int, int], None]] = None
    ) -> None:
        """執行分塊下載至本地暫存檔"""
        if not self._sftp:
            raise paramiko.SSHException("SFTP 尚未連線")
        self._sftp.get(remote_path, local_temp_path, callback=callback)

    def close(self) -> None:
        """安全釋放 SFTP 與 SSH 資源"""
        if self._sftp:
            try:
                self._sftp.close()
            except Exception:
                pass
            self._sftp = None
        if self._ssh:
            try:
                self._ssh.close()
            except Exception:
                pass
            self._ssh = None
```

### 4. `core/traverse_engine.py` — 規則樹編譯與三層快取遍歷引擎（深水區 1 核心實作）

```python
import fnmatch
import os
import posixpath
import socket
import stat
import threading
import time
from collections import defaultdict
from typing import List, Dict, Set, Callable
import paramiko

from models.data_models import (
    RuleItem, SearchSettings, RemoteFileTask, TaskStats, LogLevel, TaskCancelledError
)
from core.sftp_manager import SFTPManager

class TraverseEngine:
    """
    負責將扁平規則編譯為 Rule Tree，並透過實體目錄快取機制執行三層遍歷。
    確保遠端任何一個實體目錄最多只被呼叫一次 listdir_attr()。
    """

    MAX_RETRY = 3

    def __init__(
        self,
        sftp_mgr: SFTPManager,
        initial_path: str,
        search_settings: SearchSettings,
        cancel_event: threading.Event,
        log_cb: Callable[[LogLevel, str], None],
        stats_cb: Callable[[TaskStats], None]
    ) -> None:
        self._sftp = sftp_mgr
        self._initial_path = initial_path.rstrip("/") or "/"
        self._settings = search_settings
        self._cancel_event = cancel_event
        self._log = log_cb
        self._stats_cb = stats_cb

    @staticmethod
    def compile_rule_tree(
        rules: List[RuleItem],
        global_file_pattern: str
    ) -> Dict[str, Dict[str, Set[str]]]:
        """
        將表格列預先整合為三層規則樹：
        Tree[l1_pattern][l2_pattern] = Set[file_pattern]
        """
        tree: Dict[str, Dict[str, Set[str]]] = defaultdict(lambda: defaultdict(set))
        global_pat = global_file_pattern.strip()

        valid_rules = [r for r in rules if not r.is_completely_empty()]
        # 若表格完全空白但有全域規則，自動建立一筆全選搜尋路由
        if not valid_rules:
            valid_rules = [RuleItem("", "", global_pat)]

        for r in valid_rules:
            l1 = r.l1_keyword.strip()
            l2 = r.l2_keyword.strip()
            f_pat = r.file_pattern.strip() if r.file_pattern.strip() else global_pat
            tree[l1][l2].add(f_pat)

        return tree

    @staticmethod
    def match_pattern(target_name: str, rule_expr: str) -> bool:
        """
        核心萬用字元與模糊比對演算法：
        - 留空代表全選 (True)
        - 支援 ';' 或 ',' 分隔多組條件 (OR 邏輯)
        - 含 '*' 或 '?' 走 fnmatchcase，否則自動轉為 '*keyword*' 子字串包含
        - 大小寫不敏感
        """
        expr = rule_expr.strip()
        if not expr:
            return True

        target_lower = target_name.lower()
        sub_patterns = [p.strip() for p in expr.replace(";", ",").split(",") if p.strip()]
        if not sub_patterns:
            return True

        for pat in sub_patterns:
            pat_lower = pat.lower()
            if "*" in pat_lower or "?" in pat_lower:
                if fnmatch.fnmatchcase(target_lower, pat_lower):
                    return True
            else:
                if pat_lower in target_lower:
                    return True
        return False

    def scan_all(self, rules: List[RuleItem], stats: TaskStats) -> List[RemoteFileTask]:
        """執行三層目錄遍歷，回傳去重後的待下載檔案任務清單"""
        self._check_cancel()
        rule_tree = self.compile_rule_tree(rules, self._settings.global_pattern)
        
        self._log(LogLevel.INFO, f"開始掃描遠端根目錄: {self._initial_path}")
        
        # 1. 列出 Initial Path 下的所有實體第 1 層目錄 (僅呼叫 1 次 SFTP)
        root_entries = self._safe_listdir_attr(self._initial_path, is_root=True)
        stats.scanned_dirs += 1
        self._stats_cb(stats)

        l1_dirs = [e.filename for e in root_entries if stat.S_ISDIR(e.st_mode or 0)]

        # 將匹配到的「實體 L1 目錄名」映射至其需要檢查的 {l2_pattern: Set[file_pattern]}
        matched_l1_map: Dict[str, Dict[str, Set[str]]] = defaultdict(lambda: defaultdict(set))
        for phys_l1 in l1_dirs:
            for l1_pat, l2_dict in rule_tree.items():
                if self.match_pattern(phys_l1, l1_pat):
                    for l2_pat, file_pats in l2_dict.items():
                        matched_l1_map[phys_l1][l2_pat].update(file_pats)

        self._log(LogLevel.INFO, f"第 1 層目錄比對完成，共命中 {len(matched_l1_map)} 個目錄。")

        # 2. 遍歷命中的實體 L1 目錄，找出實體 L2 目錄 (每個實體 L1 僅呼叫 1 次 SFTP)
        # 結構: matched_l2_map[(phys_l1, phys_l2)] = Set[file_pattern]
        matched_l2_map: Dict[ tuple[str, str], Set[str] ] = defaultdict(set)

        for phys_l1, l2_dict in matched_l1_map.items():
            self._check_cancel()
            l1_full_path = posixpath.join(self._initial_path, phys_l1)
            l1_entries = self._safe_listdir_attr(l1_full_path)
            stats.scanned_dirs += 1
            self._stats_cb(stats)

            l2_dirs = [e.filename for e in l1_entries if stat.S_ISDIR(e.st_mode or 0)]
            for phys_l2 in l2_dirs:
                for l2_pat, file_pats in l2_dict.items():
                    if self.match_pattern(phys_l2, l2_pat):
                        matched_l2_map[(phys_l1, phys_l2)].update(file_pats)

        self._log(LogLevel.INFO, f"第 2 層目錄比對完成，共命中 {len(matched_l2_map)} 個子目錄。")

        # 3. 遍歷命中的實體 L2 目錄，篩選第 3 層目標檔案 (每個實體 L2 僅呼叫 1 次 SFTP)
        tasks: List[RemoteFileTask] = []
        seen_remote_files: Set[str] = set()

        for (phys_l1, phys_l2), file_pats in matched_l2_map.items():
            self._check_cancel()
            l2_full_path = posixpath.join(self._initial_path, phys_l1, phys_l2)
            l2_entries = self._safe_listdir_attr(l2_full_path)
            stats.scanned_dirs += 1

            for entry in l2_entries:
                if not stat.S_ISREG(entry.st_mode or 0):
                    continue
                fname = entry.filename
                # 只要滿足該 (L1, L2) 收集到的任一 file_pattern 即排入下載
                if any(self.match_pattern(fname, fp) for fp in file_pats):
                    remote_file_path = posixpath.join(l2_full_path, fname)
                    if remote_file_path in seen_remote_files:
                        continue
                    seen_remote_files.add(remote_file_path)

                    local_file_path = os.path.join(
                        self._settings.local_save_path, phys_l1, phys_l2, fname
                    )
                    tasks.append(
                        RemoteFileTask(
                            l1_dir=phys_l1,
                            l2_dir=phys_l2,
                            filename=fname,
                            remote_full_path=remote_file_path,
                            local_full_path=local_file_path,
                            file_size=int(entry.st_size or 0),
                            file_mtime=int(entry.st_mtime or int(time.time()))
                        )
                    )
                    stats.matched_files += 1

            self._stats_cb(stats)

        return tasks

    def _safe_listdir_attr(
        self, remote_path: str, is_root: bool = False
    ) -> List[paramiko.SFTPAttributes]:
        """帶有權限攔截與斷線重試的目錄列舉封裝"""
        for attempt in range(1, self.MAX_RETRY + 1):
            self._check_cancel()
            try:
                return self._sftp.listdir_attr(remote_path)
            except PermissionError:
                self._log(LogLevel.ERROR, f"權限不足 (Permission Denied)，略過目錄: {remote_path}")
                return []
            except FileNotFoundError:
                if is_root:
                    raise
                self._log(LogLevel.WARNING, f"遠端目錄不存在，略過: {remote_path}")
                return []
            except (socket.timeout, paramiko.SSHException, EOFError) as e:
                if attempt < self.MAX_RETRY:
                    wait_sec = 2 ** (attempt - 1)
                    self._log(
                        LogLevel.WARNING,
                        f"讀取目錄網路異常 ({remote_path}): {e}，{wait_sec} 秒後重試 ({attempt}/{self.MAX_RETRY})..."
                    )
                    time.sleep(wait_sec)
                    self._sftp.reconnect()
                else:
                    self._log(LogLevel.ERROR, f"目錄重試 {self.MAX_RETRY} 次仍失敗，略過: {remote_path}")
                    return []
        return []

    def _check_cancel(self) -> None:
        if self._cancel_event.is_set():
            raise TaskCancelledError("使用者主動中止掃描")
```

### 5. `core/download_manager.py` — 本地結構鏡像、覆蓋策略與原子下載

```python
import datetime
import os
import socket
import threading
import time
from typing import Callable
import paramiko

from models.data_models import (
    RemoteFileTask, ConflictStrategy, TransferStatus, ReportRecord, LogLevel, TaskCancelledError
)
from core.sftp_manager import SFTPManager

class DownloadManager:
    """負責建立本地鏡像目錄、檢查衝突略過策略、執行 .part 原子下載與自動重試"""

    MAX_RETRY = 3

    def __init__(
        self,
        sftp_mgr: SFTPManager,
        strategy: ConflictStrategy,
        cancel_event: threading.Event,
        log_cb: Callable[[LogLevel, str], None],
        file_progress_cb: Callable[[str, int, int], None]
    ) -> None:
        self._sftp = sftp_mgr
        self._strategy = strategy
        self._cancel_event = cancel_event
        self._log = log_cb
        self._progress_cb = file_progress_cb

    def should_skip_file(self, task: RemoteFileTask) -> tuple[bool, str]:
        """根據使用者選擇的 ConflictStrategy 判斷是否略過下載"""
        if not os.path.exists(task.local_full_path):
            return False, ""

        if self._strategy == ConflictStrategy.OVERWRITE:
            return False, ""

        if self._strategy == ConflictStrategy.SKIP_EXISTING:
            return True, "本地已存在同名檔案 (策略：已存在則略過)"

        if self._strategy == ConflictStrategy.SIZE_MTIME:
            try:
                stat_res = os.stat(task.local_full_path)
                local_size = stat_res.st_size
                local_mtime = int(stat_res.st_mtime)
                # 允許 1 秒內的檔案系統時間精度誤差
                if local_size == task.file_size and abs(local_mtime - task.file_mtime) <= 1:
                    return True, "本地檔案大小與修改時間相同，略過下載"
            except OSError:
                return False, ""

        return False, ""

    def process_task(self, task: RemoteFileTask) -> ReportRecord:
        """執行單一檔案檢查與下載（含 .part 暫存保護與 3 次斷線重連）"""
        self._check_cancel()

        # 1. 檢查是否符合略過條件
        skip, reason = self.should_skip_file(task)
        if skip:
            self._log(LogLevel.WARNING, f"[略過] {task.remote_full_path} ({reason})")
            return self._make_record(task, TransferStatus.SKIPPED, reason)

        # 2. 建立本地鏡像目錄 LocalRoot / L1 / L2
        local_dir = os.path.dirname(task.local_full_path)
        try:
            os.makedirs(local_dir, exist_ok=True)
        except OSError as e:
            msg = f"無法建立本地目錄 {local_dir}: {e}"
            self._log(LogLevel.ERROR, msg)
            return self._make_record(task, TransferStatus.FAILED, msg)

        temp_path = task.local_full_path + ".part"

        def _paramiko_cb(transferred: int, total: int) -> None:
            # 深水區 4：在每個封包回呼瞬間檢查取消旗標，立即中斷大檔案阻塞下載
            if self._cancel_event.is_set():
                raise TaskCancelledError("使用者於檔案傳輸途中按下停止")
            self._progress_cb(task.filename, transferred, total)

        # 3. 帶重試機制的下載迴圈
        for attempt in range(1, self.MAX_RETRY + 1):
            self._check_cancel()
            try:
                self._sftp.download_file(task.remote_full_path, temp_path, callback=_paramiko_cb)
                
                # 原子性替換為正式檔案，並同步遠端修改時間 (供下次 SIZE_MTIME 比對使用)
                os.replace(temp_path, task.local_full_path)
                os.utime(task.local_full_path, (task.file_mtime, task.file_mtime))

                self._log(LogLevel.SUCCESS, f"[完成] {task.remote_full_path} -> {task.local_full_path}")
                return self._make_record(task, TransferStatus.SUCCESS, "下載成功")

            except TaskCancelledError:
                self._cleanup_temp(temp_path)
                raise

            except (PermissionError, FileNotFoundError) as e:
                self._cleanup_temp(temp_path)
                msg = f"檔案存取失敗 ({type(e).__name__}): {e}"
                self._log(LogLevel.ERROR, f"[失敗] {task.remote_full_path} - {msg}")
                return self._make_record(task, TransferStatus.FAILED, msg)

            except (socket.timeout, paramiko.SSHException, EOFError, OSError) as e:
                self._cleanup_temp(temp_path)
                if attempt < self.MAX_RETRY:
                    wait_sec = 2 ** (attempt - 1)
                    self._log(
                        LogLevel.WARNING,
                        f"下載中斷 ({task.filename}): {e}，{wait_sec} 秒後重連並重試 ({attempt}/{self.MAX_RETRY})..."
                    )
                    time.sleep(wait_sec)
                    try:
                        self._sftp.reconnect()
                    except Exception as reconn_err:
                        self._log(LogLevel.WARNING, f"重連嘗試失敗: {reconn_err}")
                else:
                    msg = f"網路重試 {self.MAX_RETRY} 次後仍失敗: {e}"
                    self._log(LogLevel.ERROR, f"[失敗] {task.remote_full_path} - {msg}")
                    return self._make_record(task, TransferStatus.FAILED, msg)

        return self._make_record(task, TransferStatus.FAILED, "未知錯誤")

    @staticmethod
    def _cleanup_temp(temp_path: str) -> None:
        if os.path.exists(temp_path):
            try:
                os.remove(temp_path)
            except OSError:
                pass

    def _check_cancel(self) -> None:
        if self._cancel_event.is_set():
            raise TaskCancelledError("使用者主動中止下載")

    @staticmethod
    def _make_record(task: RemoteFileTask, status: TransferStatus, message: str) -> ReportRecord:
        now_str = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        return ReportRecord(
            remote_path=task.remote_full_path,
            local_path=task.local_full_path,
            file_size=task.file_size,
            status=status,
            message=message,
            timestamp=now_str
        )
```

### 6. `core/worker.py` — QThread 工作執行緒與訊號節流閥（深水區 3 & 4 核心實作）

```python
import threading
import time
from typing import List
from PyQt6.QtCore import QThread, pyqtSignal

from models.data_models import (
    SFTPConfig, SearchSettings, RuleItem, TaskStats, ReportRecord,
    LogLevel, TransferStatus, TaskCancelledError
)
from core.sftp_manager import SFTPManager
from core.traverse_engine import TraverseEngine
from core.download_manager import DownloadManager

class ConnectionTestWorker(QThread):
    """獨立負責『測試連線』按鈕的背景執行緒，避免卡住 GUI"""
    sig_test_result = pyqtSignal(bool, str)

    def __init__(self, config: SFTPConfig) -> None:
        super().__init__()
        self._config = config

    def run(self) -> None:
        mgr = SFTPManager(self._config)
        ok, msg = mgr.test_connection()
        self.sig_test_result.emit(ok, msg)


class DownloadWorker(QThread):
    """負責完整搜尋與批次下載生命週期的背景執行緒，內建訊號節流器"""

    sig_log = pyqtSignal(str, str)                  # (LogLevel.value, message)
    sig_stats_updated = pyqtSignal(object)          # TaskStats
    sig_overall_progress = pyqtSignal(int)          # 0 ~ 100
    sig_file_progress = pyqtSignal(str, int)        # (filename, 0 ~ 100)
    sig_task_finished = pyqtSignal(bool, str, list) # (is_normal_end, summary_msg, List[ReportRecord])

    # 節流閾值：每 80ms (約 12.5 FPS) 最多發送一次進度與統計更新
    THROTTLE_INTERVAL_SEC = 0.08

    def __init__(
        self,
        sftp_config: SFTPConfig,
        search_settings: SearchSettings,
        rules: List[RuleItem]
    ) -> None:
        super().__init__()
        self._sftp_config = sftp_config
        self._search_settings = search_settings
        self._rules = rules
        self._cancel_event = threading.Event()

        # 節流狀態追蹤
        self._last_file_emit_time: float = 0.0
        self._last_file_pct: int = -1
        self._last_stats_emit_time: float = 0.0

    def request_cancel(self) -> None:
        """供主執行緒點擊『停止』按鈕時呼叫"""
        self._cancel_event.set()

    def run(self) -> None:
        stats = TaskStats()
        records: List[ReportRecord] = []
        sftp_mgr = SFTPManager(self._sftp_config)

        try:
            self._emit_log(LogLevel.INFO, f"正在連線至 SFTP 伺服器 {self._sftp_config.host}:{self._sftp_config.port} ...")
            sftp_mgr.connect()
            self._emit_log(LogLevel.SUCCESS, "SFTP 連線建立成功。")

            # 階段一：三層目錄快取遍歷
            traverse_engine = TraverseEngine(
                sftp_mgr=sftp_mgr,
                initial_path=self._sftp_config.initial_path,
                search_settings=self._search_settings,
                cancel_event=self._cancel_event,
                log_cb=self._emit_log,
                stats_cb=lambda s: self._throttled_emit_stats(s, force=False)
            )
            tasks = traverse_engine.scan_all(self._rules, stats)
            self._throttled_emit_stats(stats, force=True)

            total_files = len(tasks)
            if total_files == 0:
                self.sig_overall_progress.emit(100)
                self._emit_log(LogLevel.WARNING, "掃描完成，未找到任何符合條件的檔案。")
                self.sig_task_finished.emit(True, "掃描完成，無符合條件之檔案。", records)
                return

            self._emit_log(LogLevel.INFO, f"共找到 {total_files} 個目標檔案，開始執行下載程序...")

            # 階段二：依序下載與建立本地鏡像結構
            dl_mgr = DownloadManager(
                sftp_mgr=sftp_mgr,
                strategy=self._search_settings.conflict_strategy,
                cancel_event=self._cancel_event,
                log_cb=self._emit_log,
                file_progress_cb=self._throttled_file_progress
            )

            for idx, task in enumerate(tasks, start=1):
                record = dl_mgr.process_task(task)
                records.append(record)

                if record.status == TransferStatus.SUCCESS:
                    stats.downloaded_ok += 1
                elif record.status == TransferStatus.SKIPPED:
                    stats.skipped_files += 1
                else:
                    stats.failed_files += 1

                self._throttled_emit_stats(stats, force=False)
                overall_pct = int((idx / total_files) * 100)
                self.sig_overall_progress.emit(overall_pct)

            self._throttled_emit_stats(stats, force=True)
            summary = (
                f"任務完成！成功: {stats.downloaded_ok} | "
                f"略過: {stats.skipped_files} | 失敗: {stats.failed_files}"
            )
            self._emit_log(LogLevel.SUCCESS, summary)
            self.sig_task_finished.emit(True, summary, records)

        except TaskCancelledError:
            self._throttled_emit_stats(stats, force=True)
            msg = "任務已由使用者安全中止（已完成下載的檔案與報表均已保留）。"
            self._emit_log(LogLevel.WARNING, msg)
            self.sig_task_finished.emit(False, msg, records)

        except FileNotFoundError:
            msg = f"遠端初始路徑不存在：{self._sftp_config.initial_path}"
            self._emit_log(LogLevel.ERROR, msg)
            self.sig_task_finished.emit(False, msg, records)

        except Exception as e:
            self._throttled_emit_stats(stats, force=True)
            msg = f"任務因未預期異常中止：{type(e).__name__} - {str(e)}"
            self._emit_log(LogLevel.ERROR, msg)
            self.sig_task_finished.emit(False, msg, records)

        finally:
            sftp_mgr.close()

    def _emit_log(self, level: LogLevel, msg: str) -> None:
        self.sig_log.emit(level.value, msg)

    def _throttled_file_progress(self, filename: str, transferred: int, total: int) -> None:
        """深水區 3：單檔分塊進度雙重閘門節流器"""
        if total <= 0:
            return
        pct = int((transferred / total) * 100)
        now = time.monotonic()

        if pct == 100 or (
            pct != self._last_file_pct and (now - self._last_file_emit_time) >= self.THROTTLE_INTERVAL_SEC
        ):
            self._last_file_emit_time = now
            self._last_file_pct = pct
            self.sig_file_progress.emit(filename, pct)

    def _throttled_emit_stats(self, stats: TaskStats, force: bool = False) -> None:
        """深水區 3：目錄掃描計數節流器"""
        now = time.monotonic()
        if force or (now - self._last_stats_emit_time) >= self.THROTTLE_INTERVAL_SEC:
            self._last_stats_emit_time = now
            # 傳送拷貝避免跨執行緒競爭
            self.sig_stats_updated.emit(
                TaskStats(
                    scanned_dirs=stats.scanned_dirs,
                    matched_files=stats.matched_files,
                    downloaded_ok=stats.downloaded_ok,
                    skipped_files=stats.skipped_files,
                    failed_files=stats.failed_files
                )
            )
```

### 7. `ui/rule_table_widget.py` — 攔截 `Ctrl+V` 與 Excel TSV 自動適配表格（深水區 2 核心實作）

```python
import csv
import io
from typing import List
from PyQt6.QtCore import Qt
from PyQt6.QtGui import QKeyEvent, QKeySequence, QGuiApplication
from PyQt6.QtWidgets import (
    QTableWidget, QTableWidgetItem, QHeaderView, QMessageBox, QAbstractItemView
)
from models.data_models import RuleItem

class RuleTableWidget(QTableWidget):
    """
    自訂三層規則表格：
    - 攔截 Ctrl+V 鍵盤事件
    - 使用 csv.reader(dialect='excel-tab') 解析 Excel 剪貼簿
    - 自動適配 1欄 / 2欄 / 3欄 / 4欄以上，動態擴增列數
    """

    HEADERS = [
        "第 1 層目錄 (模糊包含，留空=全選)",
        "第 2 層目錄 (模糊包含，留空=全選)",
        "檔案名稱 (支援 *RAW*-*.csv，留空=套用全域)"
    ]

    def __init__(self, parent=None) -> None:
        super().__init__(0, 3, parent)
        self.setHorizontalHeaderLabels(self.HEADERS)
        self.horizontalHeader().setSectionResizeMode(QHeaderView.ResizeMode.Stretch)
        self.setSelectionBehavior(QAbstractItemView.SelectionBehavior.SelectRows)
        self.setAlternatingRowColors(True)

    def keyPressEvent(self, event: QKeyEvent) -> None:
        """攔截 Ctrl+V / Cmd+V 快捷鍵"""
        if event.matches(QKeySequence.StandardKey.Paste):
            self.paste_from_clipboard()
            event.accept()
            return
        if event.key() == Qt.Key.Key_Delete:
            self.remove_selected_rows()
            event.accept()
            return
        super().keyPressEvent(event)

    def paste_from_clipboard(self) -> None:
        """從系統剪貼簿讀取 Excel TSV 文字並執行智慧欄位適配填入"""
        clipboard = QGuiApplication.clipboard()
        raw_text = clipboard.text() if clipboard else ""
        if not raw_text or not raw_text.strip():
            return

        rows_data, has_truncated_cols = self.parse_tsv_text(raw_text)
        if not rows_data:
            return

        # 決定貼上起始列：
        # 1. 若有選取列，從最小選取列開始覆寫
        # 2. 若無選取，檢查最後一列是否全空，是則覆寫最後一列，否則附加於底部
        selected_indexes = self.selectedIndexes()
        if selected_indexes:
            start_row = min(idx.row() for idx in selected_indexes)
        else:
            last_row = self.rowCount() - 1
            if last_row >= 0 and self._is_row_empty(last_row):
                start_row = last_row
            else:
                start_row = self.rowCount()

        required_rows = start_row + len(rows_data)

        # 鎖定 UI 更新與訊號，確保一次貼上數千列也不卡頓
        self.setUpdatesEnabled(False)
        self.blockSignals(True)
        try:
            if required_rows > self.rowCount():
                self.setRowCount(required_rows)

            for offset, rule in enumerate(rows_data):
                target_row = start_row + offset
                self._set_row_rule(target_row, rule)
        finally:
            self.blockSignals(False)
            self.setUpdatesEnabled(True)

        if has_truncated_cols:
            QMessageBox.information(
                self,
                "欄位自動適配提示",
                "偵測到剪貼簿資料超過 3 欄，系統已自動擷取前 3 欄並忽略多餘欄位。"
            )

    @staticmethod
    def parse_tsv_text(raw_text: str) -> tuple[List[RuleItem], bool]:
        """
        深水區 2 核心演算法：
        解析 TSV 字串，清理前後空白與多餘引號，並自動適配 1/2/3/4+ 欄。
        回傳 (規則清單, 是否曾截斷第4欄以後的資料)
        """
        reader = csv.reader(io.StringIO(raw_text), dialect="excel-tab")
        parsed_rules: List[RuleItem] = []
        has_truncated = False

        for raw_row in reader:
            cleaned = [cell.strip().strip('"').strip("'") for cell in raw_row]
            # 忽略全空列 (例如 Excel 複製區塊尾端的 \r\n)
            if not any(cleaned):
                continue

            col_count = len(cleaned)
            if col_count == 1:
                rule = RuleItem(l1_keyword=cleaned[0], l2_keyword="", file_pattern="")
            elif col_count == 2:
                rule = RuleItem(l1_keyword=cleaned[0], l2_keyword=cleaned[1], file_pattern="")
            elif col_count == 3:
                rule = RuleItem(l1_keyword=cleaned[0], l2_keyword=cleaned[1], file_pattern=cleaned[2])
            else:
                has_truncated = True
                rule = RuleItem(l1_keyword=cleaned[0], l2_keyword=cleaned[1], file_pattern=cleaned[2])

            parsed_rules.append(rule)

        return parsed_rules, has_truncated

    def append_empty_row(self) -> None:
        row_idx = self.rowCount()
        self.insertRow(row_idx)
        self._set_row_rule(row_idx, RuleItem())
        self.scrollToBottom()

    def remove_selected_rows(self) -> None:
        selected_rows = sorted({idx.row() for idx in self.selectedIndexes()}, reverse=True)
        for r in selected_rows:
            self.removeRow(r)

    def get_all_rules(self) -> List[RuleItem]:
        """匯出表格內所有非空規則列"""
        rules: List[RuleItem] = []
        for r in range(self.rowCount()):
            l1 = self._cell_text(r, 0)
            l2 = self._cell_text(r, 1)
            fp = self._cell_text(r, 2)
            item = RuleItem(l1_keyword=l1, l2_keyword=l2, file_pattern=fp)
            if not item.is_completely_empty():
                rules.append(item)
        return rules

    def load_rules(self, rules: List[RuleItem]) -> None:
        self.setUpdatesEnabled(False)
        try:
            self.setRowCount(0)
            if not rules:
                self.append_empty_row()
                return
            self.setRowCount(len(rules))
            for i, rule in enumerate(rules):
                self._set_row_rule(i, rule)
        finally:
            self.setUpdatesEnabled(True)

    def _set_row_rule(self, row: int, rule: RuleItem) -> None:
        self.setItem(row, 0, QTableWidgetItem(rule.l1_keyword))
        self.setItem(row, 1, QTableWidgetItem(rule.l2_keyword))
        self.setItem(row, 2, QTableWidgetItem(rule.file_pattern))

    def _cell_text(self, row: int, col: int) -> str:
        item = self.item(row, col)
        return item.text().strip() if item else ""

    def _is_row_empty(self, row: int) -> bool:
        return not (self._cell_text(row, 0) or self._cell_text(row, 1) or self._cell_text(row, 2))
```

```python
        self.lbl_file_prog.setText(f"目前檔案: {filename} ({pct}%)")

    def _on_task_finished(self, is_normal: bool, summary: str, records: List[ReportRecord]) -> None:
        self._last_records = records
        self._set_running_ui_state(False)
        self.lbl_file_prog.setText("目前檔案: 任務結束")
        self._flush_log_buffer()

    def _set_running_ui_state(self, running: bool) -> None:
        self.btn_start.setEnabled(not running)
        self.btn_test_conn.setEnabled(not running)
        self.btn_stop.setEnabled(running)
        self.table_rules.setEnabled(not running)

    # ------------------ 深水區 3：批次日誌渲染 ------------------

    def _enqueue_log(self, level: str, message: str) -> None:
        now_str = datetime.datetime.now().strftime("%H:%M:%S")
        color = self.LOG_COLOR_MAP.get(level, "#333333")
        escaped_msg = html.escape(message)
        html_line = (
            f'<div style="margin: 1px 0; font-family: Consolas, monospace;">'
            f'<span style="color: #888888;">[{now_str}]</span> '
            f'<b style="color: {color};">[{level}]</b> '
            f'<span style="color: {color};">{escaped_msg}</span></div>'
        )
        self._log_queue.append(html_line)

    def _flush_log_buffer(self) -> None:
        if not self._log_queue:
            return
        batch: List[str] = []
        while self._log_queue:
            batch.append(self._log_queue.popleft())
        
        cursor = self.txt_log.textCursor()
        cursor.movePosition(QTextCursor.MoveOperation.End)
        cursor.insertHtml("".join(batch))
        self.txt_log.setTextCursor(cursor)
        self.txt_log.ensureCursorVisible()

    # ------------------ 輔助按鈕功能 ------------------

    def _on_clear_table(self) -> None:
        ans = QMessageBox.question(
            self, "確認清空", "確定要清空所有搜尋規則列嗎？",
            QMessageBox.StandardButton.Yes | QMessageBox.StandardButton.No
        )
        if ans == QMessageBox.StandardButton.Yes:
            self.table_rules.load_rules([])

    def _on_import_rules_file(self) -> None:
        file_path, _ = QFileDialog.getOpenFileName(
            self, "匯入規則檔案", "", "支援格式 (*.csv *.txt *.xlsx);;所有檔案 (*.*)"
        )
        if not file_path:
            return
        try:
            ext = Path(file_path).suffix.lower()
            if ext == ".xlsx":
                import openpyxl
                wb = openpyxl.load_workbook(file_path, read_only=True, data_only=True)
                ws = wb.active
                lines = []
                for row in ws.iter_rows(values_only=True):
                    cells = [str(c) if c is not None else "" for c in row]
                    lines.append("\t".join(cells))
                raw_text = "\n".join(lines)
            else:
                with open(file_path, "r", encoding="utf-8-sig") as f:
                    raw_text = f.read().replace(",", "\t") if ext == ".csv" else f.read()

            rules, _ = RuleTableWidget.parse_tsv_text(raw_text)
            if rules:
                self.table_rules.load_rules(rules)
                self._enqueue_log("INFO", f"已從檔案匯入 {len(rules)} 列規則：{file_path}")
        except Exception as e:
            QMessageBox.critical(self, "匯入失敗", f"讀取規則檔案失敗：{e}")

    def _on_browse_local(self) -> None:
        folder = QFileDialog.getExistingDirectory(self, "選擇本地儲存目錄", self.ed_local_path.text())
        if folder:
            self.ed_local_path.setText(os.path.normpath(folder))

    def _on_export_csv(self) -> None:
        if not self._last_records:
            QMessageBox.information(self, "無報表資料", "目前尚無執行紀錄可供匯出。")
            return
        default_name = f"sftp_report_{datetime.datetime.now().strftime('%Y%m%d_%H%M%S')}.csv"
        save_path, _ = QFileDialog.getSaveFileName(self, "匯出 CSV 報表", default_name, "CSV Files (*.csv)")
        if not save_path:
            return
        try:
            # 使用 utf-8-sig 確保 Windows Excel 直接雙擊打開不亂碼
            with open(save_path, "w", encoding="utf-8-sig", newline="") as f:
                writer = csv.writer(f)
                writer.writerow(["遠端路徑", "本地路徑", "檔案大小 (Bytes)", "狀態", "說明", "時間戳記"])
                for r in self._last_records:
                    writer.writerow([
                        r.remote_path, r.local_path, r.file_size,
                        r.status.value, r.message, r.timestamp
                    ])
            QMessageBox.information(self, "匯出成功", f"報表已成功匯出至：\n{save_path}")
        except OSError as e:
            QMessageBox.critical(self, "匯出失敗", f"無法寫入 CSV 檔案：{e}")

    def _on_open_local_folder(self) -> None:
        local_dir = self.ed_local_path.text().strip()
        if local_dir and os.path.exists(local_dir):
            QDesktopServices.openUrl(QUrl.fromLocalFile(local_dir))
        else:
            QMessageBox.warning(self, "提示", "本地目錄尚不存在，請先指定有效目錄。")

    def _load_saved_state(self) -> None:
        sftp_cfg, search_cfg, rules = ConfigManager.load_config()
        self.ed_host.setText(sftp_cfg.host)
        self.sp_port.setValue(sftp_cfg.port)
        self.ed_user.setText(sftp_cfg.username)
        self.chk_save_pass.setChecked(sftp_cfg.save_password)
        self.ed_pass.setText(sftp_cfg.password)
        self.ed_init_path.setText(sftp_cfg.initial_path)

        self.ed_global_pat.setText(search_cfg.global_pattern)
        idx = self.cb_strategy.findData(search_cfg.conflict_strategy)
        if idx >= 0:
            self.cb_strategy.setCurrentIndex(idx)
        self.ed_local_path.setText(search_cfg.local_save_path)

        self.table_rules.load_rules(rules)

    def closeEvent(self, event: QCloseEvent) -> None:
        """視窗關閉前自動持久化設定至 config.json，並安全等待背景執行緒"""
        if self._dl_worker and self._dl_worker.isRunning():
            ans = QMessageBox.question(
                self, "任務執行中", "目前仍有下載任務正在進行，確定要中止並關閉程式嗎？",
                QMessageBox.StandardButton.Yes | QMessageBox.StandardButton.No
            )
            if ans != QMessageBox.StandardButton.Yes:
                event.ignore()
                return
            self._dl_worker.request_cancel()
            self._dl_worker.wait(3000)

        sftp_cfg, search_cfg, rules = self._collect_current_config()
        ConfigManager.save_config(sftp_cfg, search_cfg, rules)
        event.accept()
```
